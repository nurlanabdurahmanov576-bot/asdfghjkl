# 🏎️ NEON OVERDRIVE: 3D Highway Drift

> Ураганная аркадная 3D-гонка на Three.js с процедурной бесконечной трассой, изгибами, управляемым дрифтом, трафиком и бонусами.

## 🎮 Особенности игры

- 🛣️ **Бесконечная процедурная трасса**: 4 полосы, S-образные изгибы, текстурированный асфальт и разметка, фонарные столбы и неоновые ограждения.
- 💨 **Реалистичный управляемый дрифт**: угол скольжения (slip angle), контр-руление передних колёс, клубы дыма из-под покрышек, следы шин на асфальте и комбо-счётчик очков.
- 🚗 **Разнообразие автомобилей**:
  - **Cyber GT** — футуристичный спорткар с антикрылом и неоновой подсветкой.
  - **V8 Hellcat** — мускулистый widebody маслкар с компрессором supercharger, задним спойлером-дактейлом и сплошной светодиодной полосой стоп-сигналов.
  - **Phantom EX** — обтекаемый гиперкар с максимальной управляемостью.
- 🚙 **Умный трафик**: волны автомобилей (седаны, такси, спорткары, фуры) с разными скоростями по полосам.
- 🎁 **Бонусы и пикапы**:
  - ⚡ **Нитро (N2O)** — ускорение до 220 км/ч, пламя из глушителей, эффект скорости warp-lines.
  - 🛡️ **Силовой щит** — неуязвимость и расталкивание встречных машин с искрами и физикой.
  - 🪙 **Золотые монеты** — мгновенные бонусные очки.
- 🔊 **Встроенный аудиосинтезатор**: процедурный звук двигателя, визг шин в заносе, турбо-свист нитро, звон монет и взрыв при аварии на Web Audio API (без внешних аудиофайлов).
- 📱 **Кроссплатформенность**: адаптивное сенсорное управление для смартфонов и планшетов.

## 🕹️ Управление

| Клавиша / Кнопка | Действие |
| :--- | :--- |
| <kbd>W</kbd> / <kbd>↑</kbd> | Газ / Ускорение |
| <kbd>S</kbd> / <kbd>↓</kbd> | Тормоз / Стоп-сигналы |
| <kbd>A</kbd> / <kbd>←</kbd> | Поворот влево |
| <kbd>D</kbd> / <kbd>→</kbd> | Поворот вправо |
| <kbd>Space</kbd> / <kbd>Shift</kbd> | **Управляемый ДРИФТ** |
| 🎥 Кнопка в HUD | Смена вида камеры (3-е лицо, с капота, сверху) |
| 🔊 Кнопка в HUD | Вкл / Выкл звук |
